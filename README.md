# Lectio – Enchei-vos
PWA para Lectio Divina: roteiro do Enchei-vos, ditado por voz, organização das ideias por IA gratuita, histórico por semana/dia. Funciona offline (após o 1º acesso). Sem build: sirva a pasta (`python3 -m http.server`) ou publique no GitHub Pages / Vercel e "Adicionar à tela inicial".
- Conteúdo do livro: `data/encheivos.json`
- IA: chave grátis do Google Gemini (Ajustes). Sem chave → organização local.
